# Story

The campaign story, set up Nov 21, 2026: one file per background path (from the start to Gronogon) and [Main campaign](Main%20campaign.md) for the shared story after the paths meet. **These files are canon for the story.** The rules around it (Hero's Journey paths, mentors, convergence, cast) stay in [World & story](../01%20World%20%26%20story.md) → Background paths.

- **Write them in the story editor's Story tab** (double-click **Story Editor** on the Desktop). How it works: [tools/story-editor/README.md](../../tools/story-editor/README.md).
- **Paths:** [Soldier](Soldier.md), [Acolyte](Acolyte.md), [Criminal](Criminal.md), [Sage](Sage.md), [Folk Hero](Folk%20Hero.md), [Noble](Noble.md). Each path's intro is its summary (moved from the Backgrounds table, Nov 21, 2026); the branch map shows it when you point at the path.
- **Quests:** [Legendary quests](Legendary%20quests.md) and [Grand temple quests](Grand%20temple%20quests.md): the story of each quest, one chapter per quest (moved from World & story, Nov 21, 2026). How quests work (map, starts, rewards) stays in World & story as rules.
- **Story comes from Ethan**, as everywhere else. Drafts and ideas are fine in the files as long as they read as drafts.

## How the files work

- **Free text**, written however it suits. Text above the first chapter heading is the file's intro, which is its summary.
- **Chapters** are `## ` headings. They make the outline down the side and the boxes on the branch map. Smaller headings (`### `) don't count as chapters.
- **Links** are ordinary markdown links, so they also work when reading the files anywhere else:
  - a scene: `[Ambush at the ford](../scenes/ambush-at-the-ford.json)`. If that scene file doesn't exist yet, the scene is **to write**: the editor lists it and can create it with one click.
  - a character: `[Mel](../characters/Mel.md)`.
- Links show the current name of what they point to. Renaming a character, or changing a scene's title or file name, in the editor rewrites the links here and in the design docs.
- Scenes and characters show which chapters link to them (their **In the story** list).
